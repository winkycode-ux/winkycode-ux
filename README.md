## About Me / Обо мне

### English

I am a Full-Stack Developer working across the modern JavaScript and TypeScript ecosystem. I enjoy taking ideas from an initial concept to a complete, deployed product—designing the interface, building the application logic, connecting databases, and preparing the project for production.

On the frontend, I create responsive and intuitive interfaces with React, Next.js, and Vue.js. I use component-driven architecture, predictable state management, and utility-first styling to keep applications consistent, maintainable, and pleasant to use.

On the backend, I build REST APIs and application services with Node.js, Express.js, and NestJS. I work with both relational and document databases, structure projects for long-term growth, and use Docker and modern deployment workflows to deliver reliable applications.

My goal is not simply to make software work, but to make it clear, scalable, and easy to improve. I value thoughtful architecture, readable code, performance, and a polished user experience.

### Русский

Я фулстек-разработчик, работающий с современной экосистемой JavaScript и TypeScript. Мне нравится превращать идеи в завершённые продукты: проектировать интерфейс, создавать бизнес-логику, подключать базы данных и подготавливать приложения к публикации.

На фронтенде я разрабатываю адаптивные и понятные интерфейсы с React, Next.js и Vue.js. Использую компонентную архитектуру, предсказуемое управление состоянием и utility-first стилизацию, чтобы приложения оставались последовательными, удобными и простыми в поддержке.

На бэкенде я создаю REST API и сервисы на Node.js, Express.js и NestJS. Работаю с реляционными и документными базами данных, продумываю структуру проектов с учётом дальнейшего развития и использую Docker и современные процессы деплоя.

Моя цель — не просто написать работающий код, а создать понятное, масштабируемое и удобное для развития решение. Я ценю продуманную архитектуру, читаемый код, производительность и качественный пользовательский опыт.
